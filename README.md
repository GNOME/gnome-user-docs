# gnome-user-docs

This project contains the user and system administration guides for the
GNOME project.

You can browse the documentation, including translations, online at:

- [https://help.gnome.org/gnome-help/](https://help.gnome.org/gnome-help/)
- [https://help.gnome.org/system-admin-guide/](https://help.gnome.org/system-admin-guide/)

## Installation

You will need the following tools to build the gnome-user-docs guides:

- [meson](https://mesonbuild.com)
- [yelp-tools](https://gitlab.gnome.org/GNOME/yelp-tools/)
- [xmllint](https://gnome.pages.gitlab.gnome.org/libxml2/xmllint.html)

## Contributing

Please, follow the [contribution guide](./CONTRIBUTING.md) to know how to
contribute to the gnome-user-docs guides.

## Reporting problems

If you find problems in the documentation, please report issues:

- https://gitlab.gnome.org/GNOME/gnome-user-docs/issues/

## Discussion

If you have questions related to gnome-user-docs, you can join the
[Docs room on Matrix](https://matrix.to/#/#docs:gnome.org). 
Alternatively, you can ask on [GNOME's Discourse instance](https://discourse.gnome.org/tag/documentation).
